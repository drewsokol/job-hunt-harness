# 0001: Build in Go

Status: Accepted, 2026-10-18

## Context

The reference implementation is a pair of Python scripts. jhh is an MCP server that the user's agent launches at the start of every session, so installing and starting it has to be painless.

## Decision

Write jhh in Go, using the official MCP Go SDK, pure-Go SQLite (`modernc.org/sqlite`), and the standard library for HTTP. Ship it as a single binary.

## Reasons

- **Distribution.** One binary, with no language runtime, package manager or virtualenv. `claude mcp add jhh -- jhh` is the whole setup.
- Fast startup for a process the agent starts over and over.
- Easy cross-compilation for Windows, macOS and Linux. Pure-Go SQLite keeps cgo out of the build.
- Goroutines fit concurrent feed fetching.

Speed of filtering was **not** the reason. Fetching is limited by the network, and filtering a few thousand titles takes milliseconds in any language.

## Costs

- The reference logic has to be ported, about 300 lines.
- Fewer casual contributors write Go than Python.
